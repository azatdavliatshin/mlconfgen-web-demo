Generate 3D molecular conformers from a shape constraint — no server, no upload. The model runs entirely client-side on your own machine via ONNX Runtime Web.

Configure Generation

The shape constraint is a triplet of moment-of-inertia eigenvalues. Presets approximate common ligand geometries. Each also sets the atom count and variance below — edit any of them and the shape becomes Custom.

Molecules per run — in Animate, one trajectory each. Runtime scales with this.

More steps → better quality, proportionally slower.

Animate streams every denoising step — about twice the time of Generate. “Live bonds” also predicts bonds on every frame, so you see connectivity form; that adds only a few percent.

Random shape picks a molecule shape from a sample of ChEMBL bundled with the package and generates for it. It uses Samples, Diffusion Steps and Seed; the shape preset, MOI eigenvalues, atom count, variance and mode do not apply — the atom count comes with the shape.
